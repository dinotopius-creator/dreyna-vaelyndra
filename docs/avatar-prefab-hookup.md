# Avatar prefab hookup

When UniVRM import is complete, place the generated prefab at:

`Assets/ThirdParty/AvatarBases/Prefabs/VaelyndraPremiumFemale.prefab`

The runtime will try to load this prefab automatically from:

`Resources/AvatarBases/Prefabs/VaelyndraPremiumFemale`

If that resource is not present, the world falls back to the procedural avatar.
